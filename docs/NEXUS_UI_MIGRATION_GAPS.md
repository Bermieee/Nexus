# Nexus UI coverage gaps

These are known subsystem surfaces that are not blockers for the Area 52 UI transplant. They should receive native Nexus/UI.Core representation in later iterations rather than preserving the old Nexus UI.

- Builder / Builder2 workflows
- Maintenance / repair workflows
- Paging operator controls
- Post-turn processing workspace
- Proposal workflows not already covered by UI.Core review surfaces
- Smart Context controls/inspection
- Testing/developer workspace
- General Tools workspace
- Builder-specific Tree authoring flows

The legacy Lore Tree, Memory Bank, and Character Bank interfaces are intentionally excluded from this list because those systems are being replaced by the World Tree model rather than re-created.
